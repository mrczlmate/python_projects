# Python Projects Collection

This repository includes various Python-based projects, ranging from machine learning applications to basic automation and experiments. Each folder represents a separate project or experiment.

---

### 📁 handwritten_recognitions
- **Language:** Python
- **Description:** Contains multiple solutions (e.g., using Pygame, neural networks) for recognizing handwritten digits or characters.

---

### 📁 little_first_try_projects
- **Language:** Python
- **Description:** A set of beginner-to-intermediate level projects covering various topics:
  - `cifar10_cnn_model.h5`: Trained CNN model on CIFAR-10 dataset.
  - `image-classifier.py`: Script for classifying images using a machine learning model.
  - `recommendation.py`: Basic recommendation system logic.
  - `sentiment-analysis.py`: Sentiment analysis using NLP.
  - `voice-assistant.py`: Simple command-based voice assistant.
